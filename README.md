# ML-G

An application designed to run two games simultaneously, allowing you to customize the target display, audio output device, CPU core allocation, CPU affinity, and controllers.

## Features
* **Display Management:** Choose which screen each game will run on.
* **Audio Routing:** Select independent audio output devices for each game instance.
* **CPU Optimization:** Allocate specific CPU cores and set processor affinity to ensure smooth performance.
* **Controller Assignment:** Assign specific gamepads/controllers to each game.

## Powered By
This tool utilizes the following utilities under the hood:
* **SpecialK:** For advanced game window, rendering, and input management.
* **SoundVolumeView:** For routing audio to specific hardware devices.
